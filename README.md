# GIS Data Integration Project

## 📋Опис завдання
Цей проєкт демонструє процес автоматизації завантаження даних з Google Sheets до ArcGIS Online з одночасним трансформуванням атрибутивних даних та геометрії для відображення на мапі.
Завдання включає:
- [ ] Обробку та трансформацію табличних даних.

- [ ] Завантаження підготовлених даних до Hosted Feature Layer у ArcGIS Online.

- [ ] Використання ArcGIS API for Python для роботи з шарами та атрибутами.

### 🛠️Технології та стек
- Python 3.9+

- Pandas — для роботи з табличними даними

- ArcGIS API for Python — для інтеграції з ArcGIS Online

- Google Sheets API — для завантаження вихідних даних

- REST API ArcGIS — комунікація з Feature Layer

### ✨Послідовність роботи скриптів
1. **Завантаження даних за допомогою google_loader.**
Отримуються сирі дані з Google Sheets.
Зберігаються локально для перевірки.
2. **Трансформація даних за допомогою transform_data.** 
Розкриває значення колонок Значення 1 … 10 у множину рядків:
Якщо у колонці Значення N > 0, створюється стільки рядків, скільки значення.
В інших колонках ставиться 0.
Конвертує координати у формат float для ArcGIS.

### Джерела даних
Google Sheets: Таблиця з колонками:

| Дата     | Область       | Місто     | Значення 1 | Значення 2 | … | long      | lat       |
| -------- | ------------- | --------- | ---------- | ---------- | - | --------- | --------- |
| 01.01.25 | Тернопільська | Тернопіль | 3          | 3          | … | 30,252525 | 50,252525 |

→ перетворюється на 3 рядки з 1 у колонках значень 1 та 2, інші значення 0.

3. **Завантаження до ArcGIS за допомогою arcgis_uploader**
Конвертує атрибути в формат, який приймає ArcGIS:
Дата → Unix timestamp у мілісекундах
Текстові та числові поля без змін
Створює features з координатами та атрибутами.
Додає до Feature Layer методом edit_features.

### Результат виконання
На мапі ArcGIS Online з’являються точки. 

При кліку на точку відображається popup із:
- Датою (d_date)
- Областю (t_region)
- Містом (t_city)
- Значеннями (i_value_1 … i_value_10)

Всі дати конвертовані у правильний формат, дублікати відфільтровані по набору полів [Дата, Область, Місто].
